## 🔧 Інструкція вимкнення (по кроках)

### Крок 1: Перейти в GitHub Actions
1. Відкрийте: https://github.com/starWoshe/lumara/actions
2. У лівому меню побачите список воркфлоу

### Крок 2: Вимкнути кожен воркфлоу
Для кожного воркфлоу з списку вище:

1. Клікніть на назву воркфлоу (наприклад, "LUMARA Academy — Пости в Telegram")
2. Клікніть кнопку **⋯** (три точки) в верхньому правому куті
3. Виберіть **Disable workflow**

**Приклад посилання на кожен воркфлоу:**
```
https://github.com/starWoshe/lumara/actions/workflows/[WORKFLOW_ID]
```

### Крок 3: Перевірити результат
Після вимкнення всіх воркфлоу, статус повинен змінитися на **Disabled** біля кожного.
